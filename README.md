# Obsidian-Newledge

本仓库基于[新枝](https://www.xinzhi.zone) 提供的 Obsidian 插件，提供了更新的自定义选项（包括自定义根目录、自定义导入自带的标签和分类等）。

受限于本人精力，本仓库于2026-05-07停止更新。

## 使用

1. 下载并安装源代码，放置到仓库对应插件文件夹，并启用插件。

2. 使用新枝 App 扫描插件中的二维码，首次扫码会绑定新枝账户。扫码入口：个人页 > 数据联动 > 同步到 Obsidian 桌面端。

3. 绑定完成后，就可以将新枝数据同步到 Obsidian 中了，插件提供定时同步功能和手动同步功能，可根据情况使用。

4. 推荐和 Obsidian 核心插件“日记”一起使用，从新枝同步来的数据中会带有“关联日记”属性，方便与时间建立关系，如果使用了 Obsidian 核心插件“日记”，则可以在每日日记中通过反向链接看到从新枝同步过来的数据。
